# Boundary and safety

This v0.1 project accepts fabricated, versioned source-index and Register-observation fixtures only. It does not download, store, extract, index, compare, or redistribute legal text; call a Register API; use an LLM; update an accounting skill; create an issue; email anyone; or interact with a client file.

The output is an open technical-review queue. It does not establish current law, tax effect, advice, an applicable deadline, or a workflow change. Real source access and any technical-tax decision require separate authorised processes.
