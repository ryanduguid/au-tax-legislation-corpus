# Fabricated live-evidence contract fixture

`evidence-bundle.v2.json` is a fabricated contract example, not a captured Register
response or evidence about the named instrument. Its identifiers, dates and title
must not be cited as legal facts. The retained response bytes, lengths and digests
are internally consistent and tested.

The production contract requires Federal Register URLs, so this fixture retains
those hostnames to exercise the same validation. Tests never fetch them. Do not
publish this fixture as live evidence.
